# 📖 AI 동화 낭독기

말로 주제를 들려주면 AI가 그림 동화를 쓰고, 그림을 그리고, 등장인물마다 다른 목소리와 감정으로 **실시간으로** 읽어 주는 내부망 웹 서비스입니다.
외부 유료 API 없이 이 PC의 GPU와 사내 LLM 서버만 사용합니다.

```
🎤 말로 주제 ──STT(Whisper)──▶ 주제 글
                                   │
                ┌──────────────────┘
                ▼
     ✍️ 사내 LLM (스트리밍, think 끔) ── 한 줄씩 ──┬──▶ 🔊 TTS 스트리밍 (줄마다 화자·말투·감정 지시)
        제목 / 등장인물 / 페이지 / 대사·해설        │        → 음성 조각을 바로 브라우저로
                                                  └──▶ 🎨 SDXL-Lightning (페이지 장면 그림)
                                                              → 완성되는 대로 화면에
```

접속: **https://<서버-IP>:8502** (마이크 때문에 HTTPS)

## 기능

| 기능 | 설명 |
|---|---|
| 🎤 말로 주제 말하기 | 브라우저 마이크로 녹음 → Whisper large-v3-turbo 가 받아쓰기 (문장 하나 약 0.2초) |
| 〰️ 녹음 파형 | 녹음하는 동안 실시간 막대 파형 + 경과 시간, 녹음이 끝나면 전체 파형을 "✅ 녹음됨 · N초" 와 함께 그대로 남김. 바로 아래에 **📝 녹음된 말**(받아쓴 내용) 표시. 녹음기가 연 마이크를 함께 써서 마이크를 두 번 열지 않음 (브라우저 안에서만 그림, 서버 부담 없음) |
| ✍️ 실시간 이야기 | LLM 이 JSON Lines 로 한 줄씩 쓰면 그 줄을 바로 읽기 시작 (첫 소리 약 3초) |
| 🎭 대사 연기 | 등장인물마다 목소리 유형(아이·어른·할머니·동물 등) → 화자 자동 배정 (해설자와 겹치면 같은 성별·나이대 후보 `VOICE_ALTS` 안에서 다른 목소리). 줄마다 감정 지시 (예: "깜짝 놀라 숨을 들이켜며 높고 빠르게") |
| 🎨 삽화 | SDXL + SDXL-Lightning 4단계, GPU 상주로 **한 장 약 1~2초**. 쪽마다 그리는 게 아니라 LLM 이 장면이 바뀌는 줄(장소 이동, 새 인물 등장, 결정적 사건)에 삽화 전환을 표시 → 그 줄을 읽기 시작할 때 그림이 부드럽게 바뀜. 6가지 그림체, 등장인물 생김새를 매 삽화에 넣고 같은 시드로 그림체 유지 |
| 🧸 주인공 모습 유지 | 표지를 먼저 그리고, 이후 삽화는 표지를 참고 그림으로 써서(IP-Adapter Plus) 주인공의 색·눈·그림체를 비슷하게 유지. 참고 강도 `REF_SCALE=0.2` (0.3 이상이면 장면까지 표지를 닮아 감) |
| 📚 장(챕터) 구성 | 장 수 1~5장 × 장마다 2~6쪽. 장별 제목·줄거리를 직접 정하거나 AI 에게 맡김. 새 장이 시작되면 "제1장. 제목." 을 읽고, 재생기의 장 버튼으로 이동 |
| 🔀 선택형 동화 | 장이 끝날 때마다 해설자가 "○○는 어디로 갈까요? 첫 번째, …. 두 번째, …." 하고 묻고, 아이가 **버튼을 누르거나 🎤 말로 대답**하면 그 선택대로 다음 장을 이어 씀. 선택 칸은 질문을 읽기 시작할 때 나타남. 장 경계는 코드가 지킴(LLM 이 질문을 빠뜨리면 짧은 LLM 호출로 질문을 따로 만듦). 말한 대답은 선택지 낱말·'첫 번째/두 번째'로 맞춤. 5분간 대답이 없으면 첫 번째로 진행 |
| 📏 쪽수 정확히 | LLM 이 쪽 번호를 매기며 쓰고, 코드가 강제: 덜 쓰면 남은 쪽을 이어 쓰게 다시 요청(최대 3번), 더 쓰면 넘친 내용을 마지막 쪽에 붙여 결말은 살리고 쪽수는 맞춤 |
| 🎙️ 해설 목소리 | 여자 · 다정한 / 젊은 여자 · 부드러운 / 남자 · 차분한 / 젊은 남자 · 밝은 / 할머니 / 할아버지 + 해설 느낌(다정한 엄마, 동화 구연가, 잠자리 동화 등) |
| 📖 책 재생기 | 음성 조각을 끊김 없이 이어 재생, 지금 읽는 줄 강조 + **글자 따라 읽기**(읽은 글자는 진하게, 남은 글자는 연하게 — 읽기 연습용), 자동 페이지 넘김, 멈춤/이전/다음/처음부터. 넓은 화면에서는 스크롤해도 재생기가 따라옴 |
| 📚 책장 | 만든 책을 저장해 두고 다시 읽기 / 삭제 |
| ⏳ 동시 사용 | 동시에 최대 2권(`MAX_BOOKS_AT_ONCE`). 넘으면 "앞에 N권이 만들어지는 중" 표시. 선택형 동화가 대답을 기다리는 동안엔 차례를 양보하고, 대답 뒤엔 대기열 맨 앞. TTS 는 "재생보다 앞서 만들어 둔 음성"이 적은 책(곧 끊길 책)의 문장부터 만듦 |
| 👋 누르자마자 인사말 | 서버 시작 때 해설자 × 해설 느낌 조합별 인사말을 미리 만들어 두고, 누르는 즉시 캐시에서 읽음 → 그동안 LLM 이 제목을 씀 |
| 🔢 숫자 읽기 | "3살" → "세 살", "20마리" → "스무 마리", "2025년" → "이천이십오년" (읽을 글에만, `textnorm.py`) |
| 📊 통계 | 지금 만드는 책·대기, 저장 용량, 완료율, 첫 소리, 삽화 시간, 동화 길이, 서버 전환·한자 수정 횟수, 책별 기록 |
| 🛡️ 안정성 | 한국어 문장에 한자·중국어·영어 단어가 섞이면 읽기 전에 그 줄만 LLM 으로 한글로 고침 (실패하면 그 글자만 지움) · LLM 서버가 응답하지 않으면(연결 5초 제한) 다른 사내 서버로 자동 전환해 쓴 데까지 이어서 씀 |

### 실시간 성능 (RTX 4080 SUPER, 4쪽 동화 기준 측정)
- 버튼 클릭 → 첫 소리: 약 0.3~0.5초 (미리 만들어 둔 인사말을 바로 읽고, 그동안 LLM 이 제목을 씀. 실제 브라우저 측정)
- 두 명이 동시에 만들어도 첫 소리 0.3~0.5초, 문장 중간 끊김 없음 (TTS 우선순위 + 재생기 버퍼)
- 음성 126초 분량(4쪽, 인물 4명)을 54초에 생성 → 읽는 속도보다 항상 앞서서 끊기지 않음
- 삽화: 한 장 약 1.5초 (1024×768, 4단계, GPU 상주, 주인공 모습 유지 포함. 혼자 그릴 때 0.8초, 음성 생성과 동시에 돌면 1.5초 안팎) → 장면이 바뀌는 줄을 읽기 전에 준비됨
- 받아쓰기: 문장 하나 약 0.5초 (평소 RAM 에 있다가 받아쓸 때만 GPU 로)
- 페이지 사이 쉼 약 1.2초. 표지에서는 제목 다음에 LLM 이 쓴 짧은 도입 인사(빠뜨리면 "자, 그럼 이야기를 시작해 볼까요?")를 읽어,
  그동안 LLM 이 인물 소개·1쪽을 씀 → 표지 → 1쪽도 약 1.2초 (이전 2.8~3.6초)
- 쪽수 시험: 2장×3쪽 → 6쪽, 1장×5쪽 → 5쪽, 2장×2쪽 → 4쪽, 3장×2쪽 → 6쪽 모두 정확 (모자람·넘침은 가짜 LLM 응답으로 보정 확인)
- 선택형: 아이가 고른 뒤 "좋아요! …" 응답 음성 0.3초, 다음 장 첫 음성 약 3초 (응답을 읽는 동안 다음 장을 씀)
- 화자가 바뀔 때 '틱' 소리: TTS 스트리밍 디코더가 매 문장 앞 약 78ms 에 똑같은 잡음을 내던 것을 `tts_app_streaming` 에서 잘라내고 페이드인 처리

## 처음 접속하는 PC: HTTPS 인증서 설치 (1회)

브라우저는 `http://IP주소` 에서 마이크를 막기 때문에 HTTPS 로 엽니다.
내부 IP 는 Let's Encrypt 같은 공개 무료 인증서를 받을 수 없어서, **사내용 무료 인증기관(CA)** 을 만들어 쓰는 방식(mkcert 와 같은 원리)입니다.

1. `https://<서버-IP>:8502` 접속 → 처음 한 번만 "연결이 비공개로 설정되어 있지 않습니다" 경고 → **고급 → 계속**
2. 왼쪽 사이드바 **🔒 보안 연결(인증서) 설치 → 🪟 Windows 설치 파일** 내려받아 실행 → 보안 경고에서 **예** (관리자 권한 불필요)
3. 브라우저를 **모두 닫고** 다시 접속 → 주소창에 🔒, 경고 없음
4. 🎤 녹음 버튼을 누르고 마이크 **허용**

- Mac·휴대폰: 사이드바의 "📱 인증서 파일" 을 받아 설치
  - Android: 설정 → 보안 → 인증서 설치 → CA 인증서
  - iPhone: 프로필 설치 → 설정 → 일반 → 정보 → 인증서 신뢰 설정에서 켜기
- 여러 PC 에 한 번에 배포: 관리자가 `certs/ca.crt` 를 그룹 정책(GPO) 의 "신뢰할 수 있는 루트 인증 기관" 에 등록
- 안전장치: 이 CA 는 **사설 IP(10.x, 172.16~31.x, 192.168.x)와 localhost 에만** 인증서를 발급할 수 있도록 이름 제약이 걸려 있어, 키가 새어도 외부 사이트를 위장하는 데 쓸 수 없습니다. 그래도 `certs/ca.key` 는 절대 공유하지 마세요.

## 서버 실행

**한 번에 켜기** (추천): `open_tts\start_all.bat` — TTS 서버를 켜고 준비될 때까지(처음 약 2분) 기다린 뒤 동화 앱을 켭니다.
Windows 로그인 때 자동으로 켜려면 `open_tts\register_autostart.bat` 을 한 번 실행하세요 (해제: `schtasks /Delete /TN "AI Story Services" /F`).

따로 켜기:

```bat
:: 1) tts_app_streaming 먼저 실행 (TTS 모델 공유, http://127.0.0.1:8601)
..\tts_app_streaming\run.bat

:: 2) 처음 한 번: 모델 다운로드 (약 12GB — Whisper, SDXL, SDXL-Lightning, IP-Adapter)
..\tts_streaming\.venv\Scripts\python.exe download_models.py

:: 3) 동화 낭독기 실행 (인증서가 없으면 자동 생성, STT·그림 모델 미리 로드)
run.bat
```

방화벽 (관리자 cmd, 1회):
```bat
netsh advfirewall firewall add rule name="AI Story 8502" dir=in action=allow protocol=TCP localport=8502
```

### 인증서 관리 (`make_cert.py`)
| 명령 | 언제 |
|---|---|
| `python make_cert.py` | 서버 IP 가 바뀌었을 때 (`.env` 의 `SERVER_IPS` 수정 후). CA 는 그대로라 각 PC 재설치 불필요 |
| `python make_cert.py --new-ca` | CA 를 새로 만들 때 (각 PC 에 다시 설치해야 함) |

서버 인증서 유효기간은 397일(브라우저 권장 한도), CA 는 10년입니다. 만료 전에 `python make_cert.py` 후 서버를 재시작하세요.

## GPU 메모리 (RTX 4080 SUPER 16GB)

TTS 모델은 **`tts_app_streaming` 프로세스에만** 올라가 있고, 이 앱은 `http://127.0.0.1:8601` 내부 API 로 함께 씁니다 (이 PC 에서만 접근 가능).

| 모델 | 메모리 | 위치 |
|---|---|---|
| TTS (tts_app_streaming) | 약 4.5GB | GPU 상주 |
| 그림 UNet·VAE + IP-Adapter (fp16) | 약 6GB | **GPU 상주** (`PAINT_ON_GPU=1`) |
| 그림의 글 이해(텍스트 인코더 2개)·참고 그림 이해(이미지 인코더) | 약 4GB (RAM) | CPU — 한 장에 약 0.3초, 참고 그림은 책마다 한 번만 계산 |
| STT Whisper large-v3-turbo (fp16) | 약 1.6GB | 평소 RAM, 받아쓸 때만 GPU |
| **합계 (화면 표시 포함, 실측)** | 평소 약 12.2GB, 최대 약 13.9GB / 16GB | |

그림 모델을 올린 뒤 GPU 여유가 `PAINT_MIN_FREE_GB`(기본 1.5GB)보다 적으면 자동으로 CPU 오프로드(한 장 약 4초)로 물러납니다.
GPU 를 쓰는 다른 프로그램(Ollama 등)을 함께 켜면 오프로드로 동작하거나 느려질 수 있습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 화면 (동화 만들기 / 책장, 반응형 배치, 인증서 설치 안내) |
| `storyteller.py` | 사내 LLM 스트리밍 → 이야기 이벤트 (깨진 JSON 줄도 최대한 복구), 이어 쓰기, 선택지 만들기, 한자 섞임 수정 |
| `book.py` | 책 만들기 백그라운드 작업: 말하기 스레드(TTS 스트리밍) + 그리기 스레드(SDXL), 장·쪽수 강제, 선택형 동화, 대기열, LLM 서버 전환 |
| `tts_client.py` | `tts_app_streaming` 의 내부 TTS API 클라이언트 (스트리밍) |
| `gpu.py` | Whisper·SDXL·IP-Adapter 모델 관리 (GPU 잠금, 인코더는 CPU·UNet 은 GPU, 메모리 부족 시 자동 오프로드) |
| `player.py` | 브라우저 책 재생기 (Web Audio 스트리밍, 줄 강조·글자 따라 읽기, 장 이동, 삽화 전환, 선택 칸 표시) |
| `micviz.py` | 녹음 중 실시간 마이크 파형 |
| `textnorm.py` | TTS 에 보내기 전 숫자·기호를 읽는 말로 |
| `stats.py` | 📊 통계 화면 |
| `make_cert.py` | 사내 CA + 서버 인증서 + Windows 설치 파일 생성 |
| `download_models.py` | Whisper / SDXL / SDXL-Lightning / IP-Adapter 다운로드 |
| `warmup.py` | 서버 시작 직후 모델 미리 로드 |

`static/books/<id>/` 에 책마다 `book.json`(내용·진행 상황, 줄마다 보여 줄 삽화 번호), `p<쪽>_<조각>.pcm`(음성 조각), `img_<번호>.png`(삽화, 0 = 표지)가 저장됩니다.

## 설정 (.env)

| 키 | 설명 |
|---|---|
| `SERVER_IPS` | HTTPS 인증서에 넣을 이 PC 의 내부 IP (쉼표로 여러 개) |
| `TTS_API_URL` | tts_app_streaming 의 TTS API (기본 `http://127.0.0.1:8601`) |
| `WHISPER_PATH`, `SDXL_*` | 모델 경로 |
| `PAINT_ON_GPU` / `PAINT_MIN_FREE_GB` | 그림 모델 GPU 상주 여부 / 상주 후 최소 GPU 여유 (부족하면 자동 오프로드) |
| `MAX_BOOKS_AT_ONCE` | 동시에 만드는 책 수 (기본 2, 넘으면 대기열) |
| `BOOK_KEEP_DAYS` | 이 날수보다 오래된 책 자동 삭제 (기본 0 = 지우지 않음) |
| `CHARACTER_REF` / `REF_SCALE` | 주인공 모습 유지(IP-Adapter) 켜기 / 표지를 따르는 정도 (기본 0.2) |
| `LLM_DEFAULT` | 기본 이야기 AI 서버 (`FREETOKEN` 권장 — STRATA 의 양자화 모델은 대사 JSON 을 자주 틀리게 닫음) |
| `STRATA_*`, `FREETOKEN_*` | 사내 OpenAI 호환 LLM 서버 (외부 유료 API 사용 안 함) |
